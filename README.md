## What is this?

One funny line from a hopeless tech support agent to a desperate customer — the kind of "have you tried turning it off and on again?" wisdom nobody asked for, delivered with total confidence and zero results.

A small deterministic program (`main.ts`) picks the line and writes it out. No AI, no randomness, no network calls — just pure, unhelpful tech support energy in a single sentence.

## Run it

```bash
node main.ts
```

This writes the line to `/output/entry.txt` — a single line, one joke, nothing else.

## Files

- `main.ts` — the program that generates the line
- `package.json` — project metadata
